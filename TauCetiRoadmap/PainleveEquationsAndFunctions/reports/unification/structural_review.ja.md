# 単一ロードマップ統合の独立した内容保持レビュー

**判定：合格。** 最終の単一計画と英日本文を、レビュー済みの分冊版に対して独立に比較した。梱包された検査スクリプトを実行し、**4,975件の検査、失敗0件**を確認した。今回の判定は、数学的仕様の保持と統合の整合性についてのものであり、収録された定理の証明完了を意味しない。

## 担当と方法

本文と計画の統合を行う担当とは別の `unify_content_review` が、原文、変更する参照規約、配置に関する46件の明示的な文章変更を点検した。検査スクリプトは文書生成スクリプトを読み込んで実行することなく、許可した変換を独立に適用して原文と比較する。

旧版の6計画・12本文・再利用方針2本文・依存グラフ・登録情報・文献一覧からなる23ファイルを `before.zip` に保持する。梱包された検査スクリプトの既定実行では、このアーカイブを一時ディレクトリに展開して比較し、終了時に展開先を削除する。旧版の計画を現行の実行対象として登録しない。

## 保持を確認した内容

| 項目 | 確認結果 |
|---|---:|
| 単一計画の目標 | 77個、旧目標との一対一対応 |
| 構成・法則 | 214件、各フィールドを保持 |
| 数学的検証例・反例 | 257件、各フィールドを保持 |
| 内部依存辺 | 321本、対応写像の下で完全に一致 |
| 外部依存条件 | 各目標で文字列・順序を保持 |
| 文献記録 | 24件、ファイルのバイト列も一致 |
| 本文の原文単位 | 14件、英日双方の全文を比較 |
| 層 | 19層、各部の順序と目標配置を保持 |

目標の主張、入力条件、法則、反例、文献位置、証明範囲、旧日本語翻訳フィールドを、明示的な内部アドレス変更以外は保存した。本文については、目標フィールドに含まれない文章も比較した。外部供給元への正確な条件、各層の例、モジュライ構成の完了条件、日本語の付録A・B、出典の適用範囲と留保を含む。

旧版の構成単位ごとの上位メタデータは移設表に完全に保持する。現行の各部の記録は、所有関係・単一計画への参照・現在の提供状態を明確にする配置上の変更を伴う。旧メタデータを現行の構造と混同しない。

## 再利用性と内在性

依存グラフが非巡回であることに加えて、次の推移的依存条件をすべて確認した。

- 一般理論のN・M・A・C部は、P・G部の適用目標に依存しない。
- 五極のG部は、パンルヴェのP部に依存しない。
- P1–P8の内在的構成は、P9の古典的スカラー表示に依存しない。

統合は物理的な配置と参照方法の変更である。同じ一般定理・構成・比較写像を利用する関係を保ち、不要な依存辺を追加していない。全77目標をロードマップの実施対象としつつ、条件付きの分枝に必要な仮定は元の記述のまま保持している。M4の見出しから「Optional／選択的」を除いた変更は、この実施範囲を明確にするものであり、各定理の仮定を削除するものではない。

## 検出した所見と閉鎖

**DOC-01（軽微、閉鎖）**：再利用方針の末尾に、旧44番号がそのまま不変であるかのような説明と、前の分冊版の数学レビューを現在のレビューと呼ぶ英語表現が残っていた。

修正後は、旧ローカル番号を接頭辞P付きの正式番号として保持すること、全対応を移設表で記録することを英日双方で明記した。前の数学レビューと今回の統合レビューの参照先も区別した。最終検査で修正箇所を確認し、この所見を閉鎖した。

46件の配置・参照説明の変更を一つずつ確認し、その一覧のハッシュを検査スクリプトに固定した。確認後に新しい文章変更を追加すると、この検査は不合格になる。ユーザーの後続指示に基づくfork先のドラフトブランチへの反映に関する状態表示も、この配置上の変更に含む。このレビュー担当はリモート変更を行っていない。

## 再現と判定の境界

ロードマップのルートから次を実行できる。

```bash
python3 reports/unification/validate_one_roadmap.py
```

既定の出力は `reports/unification/validation.rerun.json` であり、凍結された今回の判定記録を上書きしない。基準版や候補版を明示する `--before`、`--candidate`、出力先を指定する `--output` も使用できる。

最終の対象ファイルのハッシュ、すべての検査、所見の閉鎖記録は `structural_review.json` に保存した。機械的検査は定理の真偽を証明しない。今回確認したのは、前の数学レビューを通過した内容を、一つのロードマップへ欠落なく移し、その条件・依存関係・再利用性を保持したことである。
