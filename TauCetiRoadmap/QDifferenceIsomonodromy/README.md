# Roadmap: q 差分方程式と等モノドロミー変形

**Summary.** 複素数 q を 0 < |q| ≠ 1 の範囲で固定し、任意の有限階数の有理 q 接続、その局所解析データ、大域接続データを保存する離散変形を構成する。基本対象は、有理関数体上の q 差分加群と、射影直線上のベクトル束 E に備わる有理型同型 A : E ⇢ σ_q*E である。σ_q(z) = qz とする。行列表現 Y(qz) = A(z)Y(z) は、この対象に基底を選んだ表示として扱う。

局所理論は共鳴、非半単純な正則特異部分、有理数の傾きを含む。傾きフィルトレーションと形式分類を構成し、形式型を固定した解析的同型類を楕円曲線 E_q = ℂ×/q^ℤ 上の q-Stokes 層の第一非可換コホモロジーで分類する。整数傾きの正規形から分岐と降下を通じて有理傾きへ進み、正則特異の場合を傾き零の特殊化として得る。

大域理論では、0 と ∞ の局所解析 q 差分加群を保持し、それぞれの楕円曲線上の実現を結ぶ有理型同型を接続データとする。局所モデルの延長と有理型行列の貼り合わせにより、有理 q 差分加群の圏との同値を構成する。正則特異の場合には、局所定数行列と Birkhoff 接続行列による分類を回収する。

等モノドロミー変形は、時間の自己同型に沿う接続データの同型と、その合成の整合性から定式化する。複数方向の輸送では各方向の零曲率方程式と方向間の cocycle 条件をともに課す。接続データの同型を有理 q 接続の同型へ持ち上げ、束の模型と局所格子を指定した上で、その変更として離散 Schlesinger 変換を記述する。解析的パラメータ依存を主張する場合には、その正則性を保証する仮定と構成を独立に指定する。

FormalLaurentPuiseux の形式係数体、AlgebraicVectorBundles の束と引戻し、ComplexManifolds と ComplexTori の解析的商と降下、SpecialFunctionsTheta の theta 関数を利用する。PainleveEquations の一般等モノドロミー理論は微分方程式との比較の基準とし、q 差分の分類定理と変形定理は差分方程式固有の理論として構成する。

## Conventions

代数的定義は、可換環 R と環自己同型 σ の上で与える。複素解析では |q| > 1 とし、0 < |q| < 1 の方程式は q を q⁻¹、A(z) を A(q⁻¹z)⁻¹ に取り替える同値によって扱う。0 の局所係数体は収束 Laurent 級数体 ℂ({z})、形式係数体は ℂ((z))、∞ の局所座標は w = z⁻¹ とする。

列ベクトルの方程式を σ_qY = AY と書き、対応する半線形作用素は Φ_A = A⁻¹σ_q とする。解の表示を Y′ = GY に変えると A′ = (σ_qG)AG⁻¹ となる。q 接続は E ⇢ σ_q*E の向きに取り、極集合には A の極と A⁻¹ の極をともに含める。

時間の自己同型 T は差分変数の作用 σ_q と可換とする。輸送 Y(z,Tt) = B(z,t)Y(z,t) の整合式は A(z,Tt)B(z,t) = B(qz,t)A(z,t) である。時間の選択、局所格子、局所フレーム、行列式の制約は、それぞれ与えるデータとして区別する。

## Scope and ownership

本ロードマップは、q 差分加群、局所形式・解析分類、大域接続データ、接続保存変形、局所格子変更を所有する。対象の階数を二に制限せず、局所理論と大域比較では共鳴を許す。具体的な正規化や変形定理が追加仮定を要するときは、その仮定を該当する主張に置く。

個別の q-Painlevé 方程式、反標準曲面の分類、クラスター実現、ミラー対称性は本ロードマップの対象に含めない。微分方程式の接続と等モノドロミー理論は PainleveEquations の所有範囲である。
